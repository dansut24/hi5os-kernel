# Build 88 — Hi5WebCore native engine foundations
Preserves Build 87 at baseline/v0.3.5-build87-graphics-browser. Introduces original bounded Rust DOM node tree with parent/child/sibling links, computed nested styles, inherited text colour and alignment, simple box padding/margins, center alignment, and real same-origin GET search form (one visible named text/search input, explicit submission, no hidden or password fields, no POST). Form query percent encoding and independent server-side receipt tested. Four address-based tabs, refetch on switch (shared history and one live document; not concurrent browser processes), Ctrl+T/Tab/W. Opt-in auto graphics Ctrl+Shift+I retains bounded resource limits and synchronous networking; default manual to avoid blocking desktop on slow sites. Existing PNG/JPEG, TLS and download gates retained. Full HTML5 tree construction, CSS property cascade/descendant selectors, Flexbox/Grid, WebP/SVG, fonts, full forms, larger downloads, cookies and general sandboxed JS pending. Current procman is bookkeeping only; no kernel-isolated JS claimed. BBC and Google are public targets, not full visual acceptance yet.
Textareas used as single search fields are included; disabled and readonly fields excluded. Public Google form discovery diagnostic non-blocking; mandatory isolated HTTP test checks actual GET query receipt, response rendering, tab switching and close. No claim of full public Google search until manual evidence.
