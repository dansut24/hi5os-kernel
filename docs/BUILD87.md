# Build 87 — freestanding image decoder link correction
Build 86 compiled BearSSL, stb_image and Rust, but rust-lld rejected the unresolved Windows thread-local storage symbol _tls_index. Define the upstream-supported STBI_NO_THREAD_LOCALS option for the single synchronous decoder and align its fixed scratch arena to 16 bytes. Add an independent no-default-library COFF link probe to catch unintended hosted runtime dependencies before the full kernel build. No changes to the pinned upstream decoder, HTTPS validation, resource limits or mandatory CSS/PNG/JPEG/browser qualification tests. Build 85 remains the installable baseline until Build 87 passes. No production changes.
