# Build 90 — Browser chrome and bounded layout
Baseline Build 89 (5dd2144), CI 45949654645 passed. Hi5Browser now has a visible tab strip with mouse select/close/new, reload/back/forward/home, address bar, graphics/settings and last-download controls; settings (Ctrl+S) toggle automatic CSS/images, automatic restricted script preview and technical diagnostics for the current session. Per-tab URL history is restored independently (up to 16 entries per tab); switching refetches pages, not concurrent live documents. Four tabs remain the limit. Downloads button reopens the last saved download, not a general download manager. 
Hi5WebCore uses one bounded row iterator for rendering, scrolling and x/y hit-testing; basic CSS flex/grid horizontal rows for simple short single-block sibling items, two-to-four equal grid tracks and bounded gap; word wrapping, fallback to vertical flow for complex content. This is not standards-complete Flexbox/Grid or a full box model. Adds opt-in restricted textContent string concatenation with max 8 terms, bounded output and rejection of arbitrary calls. No general JavaScript runtime, sandbox, cookies, persistent settings, concurrent tab documents, or complete web compatibility. QuickJS integration deferred until kernel isolation/porting prerequisites; no unrestricted scripts run. Mandatory boot self-tests for layout and expression evaluator; existing mandatory HTTP test checks settings open/toggle/close and retains screenshot. Existing public BBC/Google diagnostics remain non-blocking. TLS and persistent OS disk unchanged.
