## Build 93 boot correction
Original CI run 45959977194 compiled successfully but the 256 MiB VM firmware refused to load BOOTX64.EFI (`Out of Resources`), before any kernel marker. Retained EFI PE SizeOfImage was 176.05 MiB. Move the heap arena from static image storage to permanently reserved contiguous conventional frames after platform initialization. The physical allocator removes reserved frames from both free and managed maps, verifies writable identity mappings and rejects release of the heap bounds. The heap uses 32 MiB on smaller managed-memory profiles, up to 40 MiB on larger profiles with 32 MiB fallback; allocation bounds and full-heap self-test use actual capacity. All existing 256/512/1024 MiB boot and browser/7-Zip gates retained. Browser resource capacities unchanged. This is a candidate fix pending full VM qualification.
