# Build 106 – Hi5FS v1
Baseline Build 105 710aff3 green and 15/15 VMware acceptance passed. First native persistent volume in unused sectors 6466–8191 (existing 16 MiB disk unchanged). Dual 17-sector catalogue banks, 1692 512-byte data blocks (866,304 bytes); 64 total entries, 14 initial directories, per-file max 256 KiB, 64-byte printable ASCII names, contiguous variable extents. Copy-on-write payloads preserve extents of both validated generations; CRC32 for payloads, catalogue and commit header, flush/readback before publish, fail closed on unknown nonzero area or conflicting catalogues, recover prior valid generation if current corrupt. No writes outside reserved range; legacy data signature required. On failed transaction current in-memory volume read-only until remount. Protected system folders and single local workspace ownership; not process-enforced multiuser ACLs, encryption, general disk partition/physical-device support, or journaled large-file filesystem. File creation/overwrite/read/copy/move/rename/remove-empty-dir, nested directories, date metadata if firmware clock available, path lookup, no directory cycles, no overwrite via copy/move/rename. 
Explorer Hi5FS button/Ctrl+H, explicit initialise, mount, breadcrumb, paginated rows, selected open, command field (help, mkdir, new, cd, open, write path; text, copy/move source; destination, rename path; name, delete then confirm, import, check, saveword, download, ls, home, up, mount). Legacy slots remain usable. Import copies existing saved notes and native Office/DOCX into Documents/Legacy, non-destructive and skips existing names; partial import can be retried. Native Word open/save and export sibling DOCX, Ctrl+Shift+S routes to named Save As in Explorer. Legacy Word behavior retained. No auto synchronisation between legacy and Hi5FS. Build 106 host fault injection and guest boot model required; separate live AHCI disk guest test added. No changes to production.
Guest qualification uses an actual AHCI data disk and three cold boots, seeds legacy note and native Word records, exercises file operations and named Word/DOCX, verifies catalogue and payload bytes independently, asserts every sector outside the reserved Hi5FS region remains identical, and corrupts newest header to test fallback. UI refuses mount when home name differs from current local account; this is workspace binding, not cryptographic access isolation. Anonymous-to-account migration not automated.
