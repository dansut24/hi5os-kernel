# Build 86 — graphical browser candidate
Preserves Build 85 HTTPS baseline (manually demonstrated BBC Sport, 1,003,869 bytes). Increases native block capacity to 2048, replaces fixed hyperlink panel with document links and scrollbar, adds bounded inline/external CSS rules (simple tag/class/id, color/background, limited font weights/sizes), and integrates pinned upstream stb_image PNG/JPEG decoder with fixed scratch arena and bounded image cache. Graphics button or Ctrl+I explicitly fetches up to 2 stylesheet and 4 image resources; HTTPS pages reject insecure asset URLs. Existing text, TLS, history, download, setup and 7-Zip tests retained. Mandatory browser fixture now tests external CSS and two decoded image formats. Existing NetSurf/litehtml considered; their runtime dependencies not currently available; no full engine port claimed. Full DOM/CSS cascade, responsive layout, WebP/SVG, external fonts, sandboxed JS, tabs and larger persistent downloads remain pending. No external rendering proxy, no production modifications. Browser remains experimental; untrusted native image decoder is not process-isolated.
