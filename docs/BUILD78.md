# Build 78 — display subsystem first
Preserves Build 77 GUI baseline, Build 61 OS baseline. Adds native QEMU Standard VGA PCI / Bochs DISPI runtime mode selection, VRAM and identity-map bounds, register readback and rollback, UEFI framebuffer fallback, six display settings modes (640x480 through 1920x1080), cursor/window reflow, maximized original 7-Zip wrapper and larger guest work area, full single-list presentation and bottom status bar. CI verifies actual QMP screenshot dimensions for each mode and requires persistent original GUI at Full HD. Software rasterization, not hardware acceleration. Other adapters, resolution persistence, list selection/navigation, dialogs and GUI archive operations remain unqualified. No changes to original application binary or stable branches.
