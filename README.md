This candidate fixes bounded HTTP body framing: Content-Length, connection-close (requires TCP FIN), chunked (validates full termination, rejects conflicting framing), basic non-executing HTML text extraction. The original raw download bytes are retained. Three independent real QEMU SLIRP tests verify 1024-byte PE fixture download, CRC, persistent save and reopen for each framing mode. Boot, document persistence and alternate subnet DHCP/DNS/routing tests retained. No data format changes.
